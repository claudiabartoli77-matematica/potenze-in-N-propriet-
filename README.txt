LE PROPRIETÀ DELLE POTENZE — GITHUB PAGES

I primi cinque gruppi di esercizi provengono dagli screenshot con soluzioni forniti da Claudia: prima proprietà 4, seconda 4, terza 6, quarta 4, quinta 4. Seguono quattro esercizi sullo zero e 18 domande tratte dallo screenshot finale. Per le uguaglianze con più completamenti possibili, l'app chiede quale opzione tra quelle mostrate funziona. Il test finale di 20 domande deriva dal PDF allegato.
